🎯 Custom Conditions & Field Patterns

Learn how to implement complex business logic for conditional masking and customize field placeholder syntax.

MaskMeCondition Interface

public interface MaskMeCondition {
    /** Sets runtime input for the condition */
    default void setInput(Object input) { }

    /** Determines if a field should be masked */
    boolean shouldMask(Object maskedFieldValue, Object objectContainingMaskedField);
}

Built-in Conditions

AlwaysMaskMeCondition

Always returns true. Use for fields that should always be masked regardless of context.

public boolean shouldMask(...) {
    return true;
}

MaskMeOnInput

Masks only when input equals "maskMe" (case-insensitive). Use for header-driven conditional masking.

public boolean shouldMask(...) {
    return input != null
        && input.equalsIgnoreCase("maskMe");
}

Creating Custom Conditions

1. Environment-Based Condition

public class EnvironmentBasedCondition implements MaskMeCondition {
    private String environment;

    @Override
    public void setInput(Object input) {
        if (input instanceof String) this.environment = (String) input;
    }

    @Override
    public boolean shouldMask(Object maskedFieldValue, Object objectContainingMaskedField) {
        return "production".equalsIgnoreCase(environment);
    }
}

// Usage
MaskMeInitializer.mask(dto, EnvironmentBasedCondition.class, "production");

2. Role-Based Condition

public class RoleBasedCondition implements MaskMeCondition {
    private String requiredRole;

    @Override
    public void setInput(Object input) {
        if (input instanceof String) this.requiredRole = (String) input;
    }

    @Override
    public boolean shouldMask(Object maskedFieldValue, Object objectContainingMaskedField) {
        String currentRole = getCurrentUserRole(); // From security context
        return !requiredRole.equals(currentRole);
    }
}

3. Value-Based Condition

public class ValueBasedCondition implements MaskMeCondition {
    private Object thresholdValue;

    @Override
    public void setInput(Object input) { this.thresholdValue = input; }

    @Override
    public boolean shouldMask(Object maskedFieldValue, Object objectContainingMaskedField) {
        if (maskedFieldValue instanceof Number && thresholdValue instanceof Number) {
            return ((Number) maskedFieldValue).doubleValue() > ((Number) thresholdValue).doubleValue();
        }
        return false;
    }
}

// Mask salaries above 100,000
MaskMeInitializer.mask(dto, ValueBasedCondition.class, 100000);

4. Time-Based Condition

public class TimeBasedCondition implements MaskMeCondition {
    private LocalTime startTime, endTime;

    @Override
    public void setInput(Object input) {
        if (input instanceof String timeRange) {
            String[] times = timeRange.split("-");
            this.startTime = LocalTime.parse(times[0]);
            this.endTime = LocalTime.parse(times[1]);
        }
    }

    @Override
    public boolean shouldMask(Object maskedFieldValue, Object objectContainingMaskedField) {
        LocalTime now = LocalTime.now();
        return now.isAfter(startTime) && now.isBefore(endTime);
    }
}

// Mask during business hours
MaskMeInitializer.mask(dto, TimeBasedCondition.class, "09:00-17:00");

5. Complex Business Logic (with DI)

@Component
public class BusinessRuleCondition implements MaskMeCondition {

    @Autowired private UserService userService;
    private String ruleType;

    @Override
    public void setInput(Object input) {
        if (input instanceof String) this.ruleType = (String) input;
    }

    @Override
    public boolean shouldMask(Object maskedFieldValue, Object objectContainingMaskedField) {
        return switch (ruleType) {
            case "GDPR_COMPLIANCE" -> isGdprApplicable(objectContainingMaskedField);
            case "USER_CONSENT"    -> !hasUserConsent(objectContainingMaskedField);
            default -> false;
        };
    }
}

Field Reference Patterns

Default Pattern: {fieldName}

public record UserDto(
    @MaskMe(conditions = {AlwaysMaskMeCondition.class}, maskValue = "{firstName}@masked.com")
    String email,

    @MaskMe(conditions = {MaskMeOnInput.class}, maskValue = "{id}-{department}")
    String displayName,

    String firstName, Long id, String department
) {}

Configuring Custom Patterns

// Set at application startup
MaskMeFieldAccessUtil.setUserPattern(Pattern.compile("\\[([^]]+)]"));

Available Pattern Options

Pattern TypeExample UsageRegex

Multiple Field References

@MaskMe(conditions = {AlwaysMaskMeCondition.class},
        maskValue = "{firstName}.{lastName}@{company}.com")
String email;

Best Practices

✅ Good — Focused Responsibility

public class AdminOnlyCondition
    implements MaskMeCondition {
    public boolean shouldMask(...) {
        return !isCurrentUserAdmin();
    }
}

❌ Avoid — Multiple Responsibilities

public class ComplexCondition
    implements MaskMeCondition {
    public boolean shouldMask(...) {
        return !isAdmin() && isProd()
            && isBusinessHours();
    }
}
  • Always validate input type in setInput() with instanceof
  • Cache expensive operations in setInput(), keep shouldMask() fast
  • Register conditions as singletons for memory efficiency
  • Use framework DI for conditions that need external services

Common Pitfalls

Thread Safety Never use static fields for input state. Use instance fields — MaskMe manages per-thread isolation via ThreadLocal.
Field Reference Limitations Cannot reference nested object fields directly: {address.street} won't work. References work within the same object level.

❌ Unsafe Casting

public void setInput(Object input) {
    this.value = (String) input;
    // ClassCastException risk!
}

✅ Safe Type Checking

public void setInput(Object input) {
    if (input instanceof String s)
        this.value = s;
}
