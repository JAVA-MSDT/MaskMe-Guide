📊 MaskMe Benchmark

Performance comparison between hardcoded masking and MaskMe's annotation-driven approach. The MaskMe-Benchmark project is a Spring Boot demo application and benchmark suite that includes a web UI, REST API, and CLI benchmark runner.

MaskMe-Benchmark Project A dedicated benchmark project lives in the MaskMe-Benchmark/ folder. It includes a web UI at http://localhost:9090 with interactive API demos, live benchmark runner, and side-by-side comparison of hardcoded vs annotation-driven masking. Run it with mvn spring-boot:run or the CLI benchmark with mvn exec:java.

Benchmark Methodology

The benchmark follows JMH-style methodology (7 of 8 best practices):

Warmup (10K iterations) → JIT compilation & C2 optimization ↓ GC Stabilization → System.gc() + 100ms pause ↓ Measurement (3 runs × 100K iterations) → Per-sample System.nanoTime() timing → Memory via Runtime.totalMemory() - freeMemory() → CPU via ThreadMXBean.getCurrentThreadCpuTime() → GC via GarbageCollectorMXBean.getCollectionCount() ↓ Multi-Run Averaging → 3 runs averaged to reduce OS/thermal variance ↓ Statistical Analysis → Sort samples → p95, p99 percentiles → Throughput = ops / elapsed time

What We Follow

PracticeImplementation
Warmup phase10,000 iterations for JIT optimization
GC stabilizationSystem.gc() + sleep between warmup and measurement
Per-sample timingSystem.nanoTime() per iteration

Real-World Context

⚠️ Don't let the microbenchmark scare you. The +9,767% compares two near-zero values in isolation. In a real web request, MaskMe adds only 0.08% overhead.

When to Use Which

Use Hardcoded When

  • Ultra-high performance (<10ms budget)
  • Simple masking (1-3 fields)
  • >10K req/sec hot paths

Use MaskMe When ✨

  • Complex conditional masking
  • Multiple DTOs / endpoints
  • Team collaboration
  • Compliance / audit trail
  • New development / microservices

Benchmark Project Details

The MaskMe-Benchmark project includes:

  • Web UI — Overview page, live benchmark runner, interactive API demo at http://localhost:9090
  • REST API — GET /benchmark endpoint for live benchmarks with configurable warmup and iterations
  • CLI Benchmark — mvn exec:java for command-line benchmark execution
  • Side-by-side comparison — Visual user cards showing masked vs unmasked fields
  • Tech Stack — Spring Boot 4.0.1, Java 21, MapStruct, Vanilla HTML/CSS/JS
