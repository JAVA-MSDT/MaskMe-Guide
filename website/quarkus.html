Step 1: Framework Configuration

@ApplicationScoped
public class MaskMeConfiguration {

    void onStart(@Observes StartupEvent ev) {
        registerFrameworkProvider();
        setupCustomConverters();
    }

    private void registerFrameworkProvider() {
        MaskMeConditionFactory.setFrameworkProvider(new MaskMeFrameworkProvider() {
            @Override
            public <T> T getInstance(Class<T> type) {
                try {
                    return CDI.current().select(type).get();
                } catch (Exception e) {
                    return null; // Fall back to reflection
                }
            }
        });
    }

    @Produces @ApplicationScoped @Unremovable
    public AlwaysMaskMeCondition alwaysMaskMeCondition() {
        return new AlwaysMaskMeCondition();
    }

    @Produces @ApplicationScoped @Unremovable
    public MaskMeOnInput maskMeOnInput() {
        return new MaskMeOnInput();
    }

    private void setupCustomConverters() {
        MaskMeConverterRegistry.clearGlobal();
        MaskMeConverterRegistry.registerGlobal(new CustomStringConverter());
    }

    void onStop(@Observes ShutdownEvent ev) {
        MaskMeConverterRegistry.clearGlobal();
    }
}

⚠️ Critical: Why @Unremovable is Required

Quarkus removes "unused" beans at build time for optimization. MaskMe looks up beans programmatically via CDI.current().select(type).get(). Quarkus doesn't see this as "usage" and removes the bean. @Unremovable tells Quarkus: "Keep this bean even if it looks unused."

❌ Without @Unremovable

Quarkus removes the bean → MaskMe falls back to reflection → 3 separate instances created for 3 fields.

✅ With @Unremovable

Bean is kept → 1 CDI singleton instance reused across all fields. Memory efficient, no reflection overhead.

When @Unremovable is REQUIRED For custom conditions with dependencies (constructor injection). Without it, Quarkus removes the bean → MaskMe tries new PhoneMaskingCondition() via reflection → fails (no no-arg constructor).

Step 2: Custom Conditions with CDI

Option 1: @Unremovable on the class (Recommended)

@ApplicationScoped
@Unremovable
public class PhoneMaskingCondition implements MaskMeCondition {

    private final UserService userService;
    private String input;

    public PhoneMaskingCondition(UserService userService) {
        this.userService = userService;
    }

    @Override
    public void setInput(Object input) {
        if (input instanceof String inputValue) this.input = inputValue;
    }

    @Override
    public boolean shouldMask(Object maskedFieldValue, Object objectContainingMaskedField) {
        boolean anyMatch = userService.findUsers().stream()
                .anyMatch(u -> u.getPhone().equals(maskedFieldValue));
        return input != null && input.equals(maskedFieldValue) && anyMatch;
    }
}

Option 2: @Produces with @Unremovable in configuration

// In MaskMeConfiguration class
@Produces @ApplicationScoped @Unremovable
public PhoneMaskingCondition phoneMaskingCondition(UserService userService) {
    return new PhoneMaskingCondition(userService);
}

Step 3: REST Resource Integration

@Path("/users")
public class UserResource {

    @Inject UserService userService;
    @Inject UserMapper userMapper;

    @GET @Path("/masked/{id}")
    @Produces(MediaType.APPLICATION_JSON)
    public UserDto getMaskedUserById(@PathParam("id") Long id,
                                     @HeaderParam("Mask-Input") String maskInput) {
        UserDto dto = userMapper.toDto(userService.findUserById(id));
        return MaskMeInitializer.mask(dto, MaskMeOnInput.class, maskInput);
    }
}

Common Issues & Solutions

"No bean found for required type" Error Add @Unremovable annotation to your condition beans or producer methods.
Beans Marked as Unused During Build This confirms you need @Unremovable. Quarkus removes beans not directly @Injected.
Constructor Injection Not Working Use producer methods with @Unremovable for conditions that need dependencies injected.
Framework Provider Returns Null Ensure beans are registered and return null on exception to allow fallback to reflection.
