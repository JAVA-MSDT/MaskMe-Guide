🔄 Scoped Converter Registry

A converter management system that provides multiple isolation levels for safe and flexible converter usage. Override or extend default type conversion behavior with priority-based, scoped converters.

Why Custom Converters?

🔧

Override Defaults

Replace default behavior for specific field types or field names.

🏢

Business Logic

Implement domain-specific masking rules (email patterns, financial rounding).

🔒

Scoped Isolation

Thread-local, request-scoped, or global — clean scope boundaries.

⚡

Priority-Based

Higher priority converters execute first. First non-null result wins.

Creating Custom Converters

Custom Email Converter

public class CustomEmailConverter implements MaskMeConverter {

    @Override
    public int getPriority() { return 10; } // Higher than defaults (0)

    @Override
    public boolean canConvert(Class<?> type) { return type == String.class; }

    @Override
    public Object convert(String maskValue, Class<?> targetType,
                          Object originalValue, Object objectContainingMaskedField,
                          String maskedFieldName) {
        // IMPORTANT: Process field references first
        String processedValue = MaskMeFieldAccessUtil
                .getMaskedValueFromAnotherFieldOrMaskedValue(maskValue, objectContainingMaskedField);

        if (maskedFieldName.contains("email")) {
            return processedValue.isEmpty() ? "[EMAIL PROTECTED]" : processedValue;
        }
        return null; // Let other converters handle it
    }
}
Important: Field Reference Processing Always call MaskMeFieldAccessUtil.getMaskedValueFromAnotherFieldOrMaskedValue() in your converter to support {fieldName} references in mask values.

Financial Converter

public class FinancialConverter implements MaskMeConverter {

    @Override public int getPriority() { return 20; }
    @Override public boolean canConvert(Class<?> type) { return type == BigDecimal.class; }

    @Override
    public Object convert(String maskValue, Class<?> targetType,
                          Object originalValue, Object objectContainingMaskedField,
                          String maskedFieldName) {
        if ("salary".equals(maskedFieldName) && maskValue.isEmpty()
                && originalValue instanceof BigDecimal bd) {
            return bd.setScale(2, RoundingMode.HALF_UP);
        }
        return new BigDecimal("0.00");
    }
}

Custom Date Converter

public class CustomDateConverter implements MaskMeConverter {

    @Override public int getPriority() { return 5; }
    @Override public boolean canConvert(Class<?> type) { return type == LocalDate.class; }

    @Override
    public Object convert(String maskValue, Class<?> targetType,
                          Object originalValue, Object objectContainingMaskedField,
                          String maskedFieldName) {
        return switch (maskedFieldName) {
            case "birthDate"  -> LocalDate.of(1900, 1, 1);
            case "hiringDate" -> LocalDate.now().minusYears(1);
            default -> null;
        };
    }
}

Converter Chain Execution

1. MaskMeInitializer.mask(dto) → MaskMeProcessor.process(dto) ↓ 2. For each field with @MaskMe annotation: ↓ 3. Check shouldMask() conditions ↓ 4. If masking needed → call ConverterRegistry.convertToFieldType() ↓ 5. Execute converters by priority: ├── User Converter 1 (Priority: 20) ← First match wins! ├── User Converter 2 (Priority: 15) ├── User Converter 3 (Priority: 10) ├── PrimitiveConverter (Priority: 0) ├── NumberConverter (Priority: 0) ├── DateTimeConverter (Priority: 0) ├── SpecialTypeConverter (Priority: 0) └── FallbackConverter (Priority: 0) ← Last resort ↓ 6. Return converted value to field

Key Rules

  • Higher priority executes first — set priority > 0 to override defaults
  • Return null to pass control — the next converter in the chain handles it
  • First non-null wins — the first matching converter that returns non-null is used
  • Field context available — you get fieldName, originalValue, the containing object, and the maskValue

Registering Converters

Global Scope (Application-wide)

MaskMeConverterRegistry.registerGlobal(new CustomEmailConverter());

Thread-Local Scope (Thread isolation)

MaskMeConverterRegistry.registerThreadLocal(new CustomEmailConverter());

Request Scope (Web requests)

MaskMeConverterRegistry.startRequestScope("request-123");
MaskMeConverterRegistry.registerRequestScoped(new CustomEmailConverter());

Usage by Framework

@Configuration
public class MaskingConfiguration {

    @PostConstruct
    public void initializeConverters() {
        MaskMeConverterRegistry.clearGlobal();
        MaskMeConverterRegistry.registerGlobal(new CustomEmailConverter());
        MaskMeConverterRegistry.registerGlobal(new FinancialConverter());
    }

    @PreDestroy
    public void cleanup() {
        MaskMeConverterRegistry.clearGlobal();
    }
}
@ApplicationScoped
public class MaskingInitializer {

    @PostConstruct
    public void init() {
        MaskMeConverterRegistry.clearGlobal();
        MaskMeConverterRegistry.registerGlobal(new CustomEmailConverter());
    }

    @PreDestroy
    public void destroy() {
        MaskMeConverterRegistry.clearGlobal();
    }
}
public class App {
    public static void main(String[] args) {
        MaskMeConverterRegistry.clearGlobal();
        MaskMeConverterRegistry.registerGlobal(new CustomEmailConverter());

        // ... process data ...

        MaskMeConverterRegistry.clearGlobal(); // Cleanup
    }
}

Testing with Scoped Converters

@ExtendWith(MockitoExtension.class)
class UserServiceTest {

    @BeforeEach
    void setUp() {
        MaskMeConverterRegistry.clearThreadLocal();
        MaskMeConverterRegistry.registerThreadLocal(new TestEmailConverter());
    }

    @AfterEach
    void tearDown() {
        MaskMeConverterRegistry.clearThreadLocal();
    }

    @Test
    void testUserMasking() {
        UserDto masked = MaskMeInitializer.mask(user);
        assertThat(masked.email()).isEqualTo("[TEST-MASKED]");
    }
}

Safety Rules

✅ DOs

  • Clear global converters at startup
  • Use thread-local for tests
  • Always clean up in finally blocks
  • Use request scope for web apps

❌ DON'Ts

  • ❌ Clear global during request processing
  • ❌ Forget to clean up thread-local (memory leak)
  • ❌ Mix scopes incorrectly

Scope Decision Tree
